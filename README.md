Personal Portfolio Website

📌 Project Description

This is a responsive Personal Portfolio Website developed as part of the Web Development Internship at Codomax Digital Solutions.

The purpose of this project is to create a professional online portfolio that showcases personal information, technical skills, projects, achievements, and contact details. It also serves as a platform to strengthen front-end web development skills while building a real-world project.

🎯 Project Objectives

- Create a clean and responsive portfolio website.
- Showcase skills, projects, and achievements.
- Improve HTML, CSS, and JavaScript skills.
- Learn Git and GitHub for version control.
- Build a professional portfolio for future opportunities.

🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
